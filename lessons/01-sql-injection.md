# الدرس 1 — حقن SQL (SQL Injection)

## شنو هي؟
الموقع لما يسجّلك دخول، يسأل قاعدة البيانات سؤال (استعلام). المشكلة إن بعض المواقع
تبني السؤال بدمج **اللي تكتبه إنت** مباشرة داخل السؤال. يعني أنت تگدر تكتب نص يغيّر
معنى السؤال نفسه — مثل واحد يكمّل جملة من غير ما تريد.

## الاستعلام المعطوب بمختبرنا
```sql
SELECT username, role FROM users
WHERE username = '<اللي تكتبه>' AND password = '<اللي تكتبه>'
```
لاحظ: اللي تكتبه يدخل بين علامتي اقتباس `'...'`.

## الاستغلال
باسم المستخدم اكتب:
```
admin' --
```
وبكلمة المرور اكتب أي شي.

يصير الاستعلام:
```sql
SELECT username, role FROM users
WHERE username = 'admin' -- ' AND password = 'اي شي'
```
- `'` تسكّر اسم المستخدم بدري.
- `--` بالـSQL تعني "تعليق"، فكل اللي بعدها (فحص الباسورد) ينلغي.
- النتيجة: دخلت كـ admin بدون ما تعرف الباسورد.

جرّب بعد:
```
' OR '1'='1
```
هذا يخلّي الشرط دائماً صحيح → يرجّع أول مستخدم.

## الخطورة
تجاوز تسجيل دخول، سحب كل بيانات المستخدمين، وأحياناً السيطرة على السيرفر كامل.

## الحل (شلون يتصلّح)
لا تدمج كلام المستخدم بالاستعلام أبداً. استخدم **Parameterized Queries**:
```python
# غلط (ثغرة):
con.execute(f"... WHERE username = '{user}'")

# صح (آمن):
con.execute("... WHERE username = ? AND password = ?", (user, pw))
```
علامة `?` تخلّي قاعدة البيانات تعامل كلامك كـ"بيانات" مو كـ"أوامر".
