# 🛡️ ورشة تدريب أمن سيبراني — Security Training Lab

مشروع تعليمي للتدرّب على أمن تطبيقات الويب **على مختبر آمن مالتنا**، بدون المساس بأي موقع حقيقي.

## المحتوى
| المجلد/الملف | الوصف |
|---|---|
| `lab/vulnlab.py` | تطبيق ويب فيه ثغرات عمداً للتدريب (بدون أي تنصيب) |
| `lessons/` | دروس مشروحة بالعربي، درس لكل ثغرة |
| `authorization-request.md` | نموذج طلب تفويض رسمي قبل أي اختبار على نظام حقيقي |

## تشغيل المختبر
```bash
python3 lab/vulnlab.py
# افتح المتصفح على http://localhost:8000
```

## الثغرات بالمختبر
1. **SQL Injection** — `/login` → `lessons/01-sql-injection.md`
2. **Reflected XSS** — `/search`
3. **IDOR** — `/profile`

## قاعدة ذهبية ⚖️
أي اختبار على نظام **حقيقي** لا يبدأ إلا بعد تفويض مكتوب + إثبات ملكية الهدف.
التدريب هنا على مختبرنا فقط.
